# Skills

| Skill | Use it when |
|---|---|
| `youtube-transcript-library/` | Harvesting or verifying YouTube transcripts for this repo. **Read `SKILL.md` §Arena first** if the host cannot reach YouTube. |

The scripts need `yt-dlp`, `deno` and `requests`; `scripts/preflight.py` tells you in five
seconds whether this host can harvest at all.
